# TradeGuard

فقط یک معامله باز در هر زمان + سقف معامله در جلسه + استراحت اجباری.

## ساخت APK
1. Android Studio را باز کن ← Open ← پوشه‌ی tradeguard (Gradle خودش sync می‌کند).
2. گوشی را با USB وصل کن (USB debugging روشن) ← Run. یا Build ← Build APK.

## راه‌اندازی روی گوشی
1. اپ TradeGuard را باز کن، پکیج اپ بروکر را بررسی کن (پیش‌فرض: com.expertoption؛
   اگر فرق دارد: تنظیمات ← برنامه‌ها ← اپ بروکر ← اطلاعات؛ یا با adb: `adb shell pm list packages | grep -i expert`).
2. «فعال‌سازی سرویس» ← TradeGuard را روشن کن.
   اگر اندروید ۱۳ گفت «Restricted setting»: تنظیمات ← برنامه‌ها ← TradeGuard ← ⋮ ← Allow restricted settings.
3. بروکر را باز کن؛ لایه فقط روی ردیف SELL|BUY ظاهر می‌شود.

## کالیبراسیون
پیش‌فرض‌ها از اسکرین‌شات ۱۰۸۰×۲۴۰۰ شما گرفته شده (x=63, y=2075, عرض=952, ارتفاع=133).
در بروکر، موقع تست، قرمز شدن لایه بعد از هر معامله را ببین. اگر کلیک به BUY/SELL نرسید، اعداد را کمی جابه‌جا کن.

## رفتار
- لمس اول: به بروکر می‌رسد و لایه قرمز می‌شود (شمارش معکوس).
- تا پایان قفل: همه‌ی لمس‌ها بلاک + لرزش.
- به سقف جلسه برسی: لایه خاکستری، تا استراحت کافی نکنی معامله نداری.
